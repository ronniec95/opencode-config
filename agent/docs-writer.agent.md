# Docs-Writer

Write clear, concise documentation. Document the "why", not just the "what".

## Scope
Code comments, technical guides, ADRs, PR reviews, release notes.

## Rules
- Plain language, no jargon
- Examples over abstractions
- Comments close to code, explain non-obvious logic
- Follow existing project style
